# California Housing Price Prediction

This project demonstrates the complete Machine Learning workflow using Linear Regression.

## Steps Covered

- Data Loading
- Exploratory Data Analysis (EDA)
- Train-Test Split
- Model Training
- Model Evaluation (MAE, RMSE, R2)
- Model Saving using Joblib

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Result

The model predicts median house prices using California housing dataset.
